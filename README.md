## 为什么做这个页面

原文档《工控Linux部署调试速查表.md》有 900 多行，命令分散在「日常精简版」「完整版」「安全与规范」中，现场查一条命令要来回滚动。

这个静态知识库把原文完整解析为：

- **38 个主题章节**，按「日常 / 完整 / 安全规范」分区；
- **224 条去重命令**（合并日常版与完整版中的重复项，原始条目 329 条）；
- **13 个故障症状** → 优先命令的快速索引；
- 每条命令可单独复制，并可一键定位回原章节。

内容不依赖任何后端、CDN 或第三方库，断网也能打开。

## 核心功能

### 1. 智能搜索（`Ctrl + K` 或 `/`）

- 命令名、中文说明、章节名、故障症状统一检索；
- 多关键词用空格分隔，例如 `相机 曝光`、`串口 变号`、`usb firmware`；
- 支持大小写不敏感、包含匹配、ASCII / 中文模糊子序列匹配；
- 结果按「章节 / 命令 / 故障症状」分组，`↑` `↓` 选择，`Enter` 定位，`Ctrl + Enter` 复制；
- 定位后自动滚动到命令所在行并高亮；搜索结果页可直接分享。

### 2. 全量指令

- 按「日常 / 完整 / 规范」分区、按章节、按关键词过滤；
- 重复命令自动合并，来源列显示所有出处；
- 一键复制、星标收藏、跳转原章节；
- 关键词过滤通过事件委托实现，重渲染后依然有效。

### 3. 故障快速索引

- 把「相机找不到」「串口变号」「端口占用」「内核升级后相机失效」等 13 个症状映射到优先命令；
- 命令芯片支持**复制**与**定位**两种操作，互不干扰。

### 4. 章节阅读

- 命令块按终端样式展示，支持复制单条 / 复制整块；
- 表格中的行内命令点击即复制；
- 右侧本页导航、滚动高亮、上一节 / 下一节；
- 脚本块（初始化脚本、for 循环）保持原样，不强行拆分；
- 一键收藏、复制本页全部命令、打印 / 导出 PDF。

### 5. 其他

- 深色 / 浅色主题，记忆到浏览器本地；
- 最近查看、我的收藏（`localStorage`）；
- 移动端抽屉导航，适配手机现场使用；
- 打印样式：自动隐藏侧栏与操作按钮，保留命令正文。

## 本地打开

直接双击 `index.html` 即可使用（所有资源都是本地相对路径）。

复制到剪贴板在部分浏览器的 `file://` 下会退化为旧版 `execCommand`；需要完整剪贴板体验时，建议起一个本地静态服务：

```bash
# 任选一种
npx serve .
python -m http.server 8080
```

然后访问 `http://localhost:8080/`。

## 内容更新

Markdown 原文是唯一内容源，页面数据由脚本生成：

```bash
# 1. 编辑原文
source/工控Linux部署调试速查表.md

# 2. 重新生成 assets/data.js
node tools/build-data.mjs

# 3. 刷新页面
```

解析约定：

| Markdown 结构 | 页面表现 |
|---|---|
| `# 第X部分｜...` | 分区（日常 / 完整 / 安全规范 / 快速索引） |
| `## 一、主题` | 章节页 |
| `### 子标题` | 章节内小节 + 右侧目录 |
| ` ```bash ` 代码块 | 终端命令块，按命令拆分（脚本块整体保留） |
| 表格 `命令 / 示例 / 用途` | 可复制、可检索的命令表格 |
| `>` 引用 | 提示 / 警告卡片 |
| 代码块上方的短句 | 自动作为命令块标题 |

新增命令时，只需在 Markdown 里补代码块或表格，再运行一次生成脚本；无需改前端代码。

## 使用提醒

- 命令以 Ubuntu / Debian 为主；不同发行版、Shell 版本可能存在参数差异；
- `sudo`、`rm -rf`、`mkfs`、`modprobe`、写 `/dev/*` 等操作请先确认设备路径与影响范围；
- 生产环境优先使用用户组与最小权限，临时 `chmod 666` 只用于验证；
- 收藏和最近记录保存在当前浏览器，不会跨设备同步；
- 搜索支持中英文，但不做拼音转换（例如输入 `xianji` 不会命中「相机」）。
